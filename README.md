# Gravio – Updates

Öffentliche Ablage der fertigen Android-Apps (APK) für **Gravio** und **Gravio Public**.
Hier liegt kein Quellcode. Die Apps lesen beim Start `gravio.json` bzw. `gravio-public.json`
und bieten neuere Versionen zur Installation an.

Die Dateien werden automatisch beim Bauen der Apps aktualisiert – bitte nicht von Hand ändern.
